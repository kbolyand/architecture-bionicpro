## Задание 1. Повышение безопасности системы
### Задача 1. Предложите архитектурное решение и доработайте диаграмму C4 для управления учётными данными пользователя.
Решение представлено на [C4 диаграмме](BionicPRO_C4_model_pkce.drawio).

Был добавлен Identity Broker + Authorization Service на базе Keycloak. Он может одновременно работать с несколькими 
внешними источниками учетных записей для пользователей, например, с ЕСИА в РФ и Online-Ausweis (eID) в Германии, а 
также внутренней Active Directory или Keycloak. В нем должны быть настроены:
- Identity Providers - внешние источники учетных записей,
- автоматическое назначение роли 'Пилот протеза' при логине через указанные выше Identity Providers,
- настроенное PKCE.

Предполагаются следующие шаги работы:
1) Приложение для донастройки протеза генерирует code_verifier и code_challenge и открывает браузер с отображением web 
приложения Keycloak.
2) Identity Broker + Authorization Service на базе Keycloak встречает пользователя, позволяет ему выбрать способ 
аутентификации(например, показывает 2 кнопки - Войти через ЕСИА Госуслуги (РФ) и Войти через Online-Ausweis (eID) в 
Германии) и, в зависимости от его страны или выбора, перенаправляет в нужную внешнюю систему.
3) Пользователь подтверждает личность через внешний Identity Provider в стране представительства. Внешний Identity 
Provider возвращает управление в Keycloak.
4) Keycloak генерирует собственный code авторизации и передает его в Android-приложение.
5) Android-приложение, используя этот code и оригинальный code_verifier, запрашивает у Keycloak финальные токены (
access_token, id_token).
6) Keycloak проверяет code авторизации и оригинальный code_verifier и возвращает финальные токены (access_token, 
id_token).
